# 単純なマークダウンより劇的に見やすい Slack Block Kit レイアウト実践ガイド

## 📐 1. 2列・3列の指定方法（マルチカラムグリッド）

Slack Block Kit では、**`layout` ブロック** を使用することで、1行の中に横並びでブロックを配置できます。

### 基本ルール
- **1行あたりの最大列数**: **1〜3 列**（`Minimum 1, Maximum 3`）
- **列数の指定**: `rows[].items` 配列に入れる要素の個数で決まります。
  - **2列にしたい場合**: `items: [ itemA, itemB ]`（2つの要素）
  - **3列にしたい場合**: `items: [ itemA, itemB, itemC ]`（3つの要素）
  - **2行 × 2列（4枚）にしたい場合**: `rows` 配列に 2 つの行オブジェクトを定義

```json
{
  "type": "layout",
  "label": "3-Column Articles",
  "rows": [
    {
      "items": [
        { "width": "standard", "block": { "type": "card", "title": { "type": "plain_text", "text": "記事 1" } } },
        { "width": "standard", "block": { "type": "card", "title": { "type": "plain_text", "text": "記事 2" } } },
        { "width": "standard", "block": { "type": "card", "title": { "type": "plain_text", "text": "記事 3" } } }
      ]
    }
  ]
}
```

### 幅（比率）の指定
各 `item` の `width` プロパティで幅の比率を制御できます：
- `narrow`: 1 （細め）
- `standard`: 2 （標準）
- `wide`: 3 （広め）
※ 左右均等の2列なら両方 `standard`、左を狭く・右を広くするなら `item1: narrow, item2: wide`（1:3 の比率）

## 📱 2. レスポンシブのオン / オフはどうやるのか？

### A. Slack 公式の仕様
- **Slack の JSON ペイロードには「レスポンシブをオフにする」という直接のフラグは存在しません。**
- Slack クライアント（デスクトップ・スマホ・iPad）側で画面幅が狭くなった際に、文字がはみ出したり読めなくなったりするのを防ぐため、**Slack クライアントが自動で Flexbox wrap（折り返し）を行う仕様**になっています。

### B. 画面幅が狭くても「絶対に横並びを崩したくない（折り返したくない）」場合の対策
Slack 上で横並びを強制したい場合は、以下の公式ブロックを使い分けます：
1. **`carousel` ブロック（横スクロール型）**:
   - スマホなどの小画面でも**絶対に下段に折り返されず、常に横1列のまま左右スワイプ（横スクロール）**になります。
   - 「縦に積み上げず、横並びを絶対に維持したい」時の Slack 公式推奨アプローチです。
2. **`table` / `data_table` ブロック**:
   - 画面幅が狭くなっても行が折り返されず、テーブル全体が水平スクロールになります。

### C. 自前Webアプリ・カスタムレンダラーでの制御
自前のアプリやダッシュボードで Block Kit をレンダリングしている場合：
- CSS の `flex-wrap: wrap`（レスポンシブ ON: 自動折り返し）と `flex-wrap: nowrap; overflow-x: auto`（レスポンシブ OFF: 横スクロール固定）を切り替えることで自由に制御できます。
- 本デモアプリの上部「**🔄 レスポンシブ折り返し: ON / OFF**」スイッチで、実際の挙動の違いを比較可能です。
